# Agent Guidelines for hoozi_radar

## Project Overview
This project serves as the **frontend web radar** for the backend software **hoozi**.

- `/index.html` is a static page.  
- `/app.js` handles data reception from the backend and controls frontend rendering behavior.  
- `/input.css` contains only one line—an `@import` directive for **Tailwind CSS v4**.  
- `/styles.css` is generated by the **Tailwind CLI**, compiled based on Tailwind class usage within `index.html`.  

Frontend resources required for map rendering (e.g., background images) are stored under the `/static/` directory.  
However, `/app.js` prioritizes fetching these static image files from the **Cloudflare R2 CDN** at:  
`https://img.hoozi.net/static/`

At the top of `/app.js`, configuration includes:
- Cloudflare R2 CDN endpoint and local static file paths.
- Multi-language translation definitions for **Simplified Chinese**, **Traditional Chinese**, and **English**.

Whenever textual content on the page changes, all three language versions must be updated accordingly, ensuring phrasing and tone are **properly localized** for each language rather than directly translated.

## Coding Conventions
- JavaScript is written using **native ES modules**. Keep logic in `/app.js` organized and use small helper functions when adding new features.  
- Always use `const` for bindings that are not reassigned, and maintain clear, descriptive naming consistent with existing code style.  
- Prefer using **Tailwind CSS v4 utility classes**. For complex or composite styles, direct CSS selectors within `/index.html` are acceptable.  

## Tooling & Workflows
Install Tailwind CLI dependencies:

```bash
npm install tailwindcss @tailwindcss/cli
```

After making any project changes, regenerate the compiled stylesheet:

```bash
npx @tailwindcss/cli -i ./input.css -o ./styles.css
```
